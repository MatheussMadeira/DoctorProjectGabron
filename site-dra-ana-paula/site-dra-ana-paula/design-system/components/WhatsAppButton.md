# WhatsAppButton

Botão de contato pelo WhatsApp, flutuante no canto da tela.

- `message` padrão: "Olá! Gostaria de saber mais sobre as próximas turmas."
- `phone`: número com DDI e DDD (só dígitos). `message`: texto que já vem escrito na conversa.
- `label`: texto do botão; no celular vira só o ícone (o texto fica para o leitor de tela).
- `floating` (padrão `true`): fixo no canto inferior direito. Use `false` para colocá-lo dentro de uma seção.
- Usa as cores da marca (`action`), não o verde do WhatsApp. Um por página.
