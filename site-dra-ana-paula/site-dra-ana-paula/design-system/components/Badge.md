# Badge

Selo curto de status ou categoria, em caixa alta.

- `tone`: `neutral` (em breve, rascunho), `accent` (categoria, modalidade), `success` (inscrições abertas, publicado), `warning` (últimas vagas), `danger` (esgotado).
- Os tons de status trazem ícone automaticamente; `icon={false}` tira.
- Uma ou duas palavras. Status sempre com texto, nunca só a cor.
