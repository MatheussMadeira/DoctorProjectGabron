# Stats

Números de credencial em linha: valor grande e rótulo.

- `items`: lista de `{value, label}`. 3 ou 4 itens. Valores como "20", "+300", "15 anos" contam de 0 até o número quando aparecem; o fio de cima se desenha. `animated={false}` desliga.
- Só números verdadeiros e verificáveis (anos de experiência, turmas, alunos). Enquanto não houver, fica o placeholder "00".
