# Reveal

Faz o conteúdo entrar suavemente (fade + leve subida) quando aparece na tela.

- Envolva um bloco: título de seção, um cartão, uma foto. `delay` em ms para escalonar uma grade (0, 120, 240).
- `as`: a tag do envoltório (padrão `div`).
- Uma vez por bloco. Desliga com `prefers-reduced-motion`.
