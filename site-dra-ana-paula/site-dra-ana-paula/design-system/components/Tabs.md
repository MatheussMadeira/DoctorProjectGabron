# Tabs

Abas de filtro com um indicador que desliza até a aba ativa.

- `items`: textos ou `{value, label, count?}`. `value` e `onChange(value)` controlam a aba ativa. `label`: nome do grupo para leitor de tela.
- Use para filtrar listas (agenda por modalidade ou cidade). Até 5 abas; mais do que isso, use um `Select`.
