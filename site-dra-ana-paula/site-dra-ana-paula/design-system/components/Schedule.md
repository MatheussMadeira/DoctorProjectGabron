# Schedule

A programação da turma em linha do tempo. A linha vertical se preenche conforme a pessoa rola e acende cada horário.

- `items`: lista de `{time?, title, description?, duration?}`. Sem `time`, numera 01, 02…
- `title`: rótulo acima ("Programação · 1º dia"). Para vários dias, use uma `Schedule` por dia.
- Use em container estreito. Títulos curtos; descrição em uma frase.
